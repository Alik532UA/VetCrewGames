# СТОРІНКИ З `noindex` ТУТ НЕМАЄ, і це рішення (BETA-CHECKLIST § 4.0,
# `BETA-NOINDEX-OVER-DISALLOW`).
#
# `/beta-test-checklists/` разом із трьома мовними адресами донедавна стояла тут
# під `Disallow` — і водночас віддавала `noindex` у власному HTML. Разом це
# гірше за кожне окремо: `Disallow` забороняє ЗАВАНТАЖЕННЯ, тож краулер
# сторінку не читає й `noindex` у ній не бачить ніколи, а адреса, на яку хтось
# послався ззовні, лягає в індекс голим URL — прибрати його нічим, бо прибирає
# рівно той тег, до якого краулер не дійшов.
#
# Відсутність рядків стереже інваріант у `src/lib/config/betaChecks.test.ts`.
#
# Групи в robots.txt НЕ успадковуються: краулер обирає одну — найточніший
# збіг за User-agent — і виконує тільки її, ігноруючи `*` цілком. Тому кожен
# блок нижче повторює той самий перелік Disallow. Це не дублювання: рядок,
# пропущений в іменованій групі, ВІДКРИВАЄ цей шлях саме названому боту
# (SEO-v8 § 7.2). Розбіжність ловить `npm run check:build`.

User-agent: *
