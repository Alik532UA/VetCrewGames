# Документація проєкту VetCrewGames

## Призначення
Документація інженерних стандартів, специфікацій міні-ігор та архітектурних рішень ігрового порталу `VetCrewGames`.

## Структура
- `adr/` — Архітектурні рішення (Architecture Decision Records).
- `specs/` — Специфікації мережевого мультиплеєру та ігрових режимів.
- `analysis/` — Звіти з продуктивності та безпеки Firebase RTDB.
